# MediPeX - Release History & Changelog

This document serves as a detailed historical record of all releases, features, and architectural updates for MediPeX.

---

## [v0.1.1] - Prototype Initial Release (2026-10-03)

**Overview:**
The very first public prototype release of MediPeX. Designed to prove the core concept of unifying local media and YouTube streaming into a single, seamless desktop application. Built on Go and Wails.

**Core Architecture & Tech Stack:**
- **Backend:** Go 1.20+ with Wails v2 framework for native OS integration and local file streaming.
- **Frontend:** Vanilla JavaScript, HTML5, and standard CSS variables (VLC-inspired theme).
- **Audio Processing:** Native Web Audio API (`AudioContext`, `BiquadFilterNode`, `GainNode`).
- **YouTube Engine:** Invidious API proxying (bypassing CORS) to extract raw `googlevideo.com` CDN streams and formats. YouTube IFrame API integration for synced playback controls.

**Key Features Implemented:**
- **Hybrid Playback:** Support for both local video/audio files (via Wails custom asset server) and direct YouTube URLs.
- **Advanced 5-Band Equalizer:** Real-time Web Audio API equalizer processing for local files with multiple built-in presets (Flat, Bass Booster, Acoustic, Electronic, Pop, etc.).
- **300% Volume Booster:** A dedicated GainNode booster that amplifies system volume up to 3x with a safety confirmation prompt.
- **YouTube Format Extractor:** Downloads raw YouTube streams (1080p, 4K, Audio-only) directly without proxy bottlenecks.
- **Custom Playback Controls:** Fully custom UI overriding standard HTML5 video controls, featuring A-B Repeat mode for looping specific segments, playback speed cycles (0.5x to 2.0x), and interactive seeking.
- **Playlist Management:** Editable, re-orderable tabular playlist. 
- **Right-Click Context Menu:** Added to playlist items to copy links, create new saved playlists, and append to existing ones.
- **Keyboard Shortcuts Engine:** Space to play/pause, Arrow keys for seeking/volume, Shift+Arrows for playlist navigation, and Shift+</> for speed control.

**Known Limitations & Future Roadmap:**
- Saved playlists are currently stored locally; future versions may feature advanced export/import.

## [v1.0] - The Aesthetics & Stability Update (2026-10-03)

**Overview:**
The official 1.0 release focuses on delivering a premium, flawless user experience by overhauling the visual design and aggressively cutting unstable features to guarantee reliability.

**Core Architectural Changes:**
- **Removal of Volume Booster & Equalizer:** In pursuit of 100% stability, the Web Audio API Equalizer and Volume Booster were permanently removed. Desktop OS restrictions prevented system-wide audio boosting without kernel drivers, and Google's IP-locking mechanisms blocked cross-origin YouTube stream processing.
- **YouTube Playback Lockdown:** Reverted permanently to the indestructible YouTube `<iframe>` embed. Playback is now zero-latency and 100% immune to API rate limits. 
- **App Metadata:** Official `MediPeX.exe` build now includes a custom designed app icon, proper window titles, and production configuration.

**Visual Overhaul (Themes Engine):**
- Introduced a dynamic CSS variables theme engine.
- Added **Default (VLC)**, **Dark**, and **Goth** themes.
- **Glassmorphism Theme:** A flagship visual upgrade featuring a deep ocean gradient backdrop with `backdrop-filter: blur(15px)` translucent frosted glass panels for an ultra-premium aesthetic.
